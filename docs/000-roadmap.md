# Research Workspace Roadmap

## Purpose

Research Workspace is intended to make academic research faster by reducing repetitive work around papers, websites, notes, summaries, references, and documents.

## Core Workflow

```text
Research topic
    ↓
Collect sources
    ↓
Read
    ↓
Select useful content
    ↓
Extract / transform
    ↓
Add to topic summary
    ↓
Organize references
    ↓
Export document
```

## Phase 1 — Foundation
-Frontend setup
-Backend setup
-Frontend ↔ backend communication
-Basic application layout

## Phase 2 — Research Workspace
-Open websites
-Display research documents
-Manage multiple sources
-Select text
-Extract text
-Add selected content to a summary
-Save summaries
-Load saved projects

## Phase 3 — Documents
-Markdown rendering
-Images
-References
-Citation management
-DOCX export
-PDF export


## Phase 4 — Intelligent Assistance
-Local text processing
-AI-assisted summarization
-Suggested additions
-Review changes
-Accept / reject changes


## Phase 5 — Knowledge Organization
-Topics
-Source groups
-Bookmarks
-Search
-Cross-source summaries
-Version history


## Rule

Each phase should produce usable software before the next phase begins.
